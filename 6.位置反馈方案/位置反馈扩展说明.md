# 位置反馈扩展实验

本轮在原正式CPU与UE仿真中增加POS R3、POS R5；两条链路统一按相对AP1路径差敏感度分配坐标bit。原七种方法、物理部署和400样本不变。新增结果目录为`results/position_phase_v1_20261018/`，不会覆盖原四组正式结果。

## 方法

UE从参考AP带噪CSI提取未量化HAQSE方向，使用原无权射线定位得到连续位置，再反馈固定域坐标索引。ULA反馈二维坐标，24 bit分配为12/12；UPA反馈三维坐标，36 bit分配为13/14/9。权重仅由公共几何的固定设计网格生成，不使用测试位置、真实信道或结果。

CPU由坐标生成所有活动AP波束。CPU相位分支进一步由该位置生成原几何LOS模型；UE相位分支本地重演同一解码，对实际波束用带噪全活动AP观测计算4 bit相对相位。位置消息与相位消息不是互相替代的字段。

## 文件

- `+posfb/`：公共配置、坐标编码/解码、CPU/UE相位、独立加权定位变体和统计。
- `verify_position_extension.m`：与旧存档功率的回归、坐标整数消息边界、功率及两分支波束一致性核查。
- `run_position_extension.m`：三个共享样本的smoke、24个独立位置的pilot、400共享位置的full模式；自动按20样本分块保存，可复用已提交块继续运行。
- `finalize_position_extension.m`：将旧七方法和新两方法合并为每组9方法，生成主图、预算图及配对比较。
- `benchmark_position_extension.m`：固定输入预热后31次本机耗时测量。
- `analyze_position_extension.py`：完整结果审计、实际等bit比较、汇总及中文报告；依赖numpy和pandas，不参与信道或估计器计算。

## 运行

在MATLAB R2024a中进入本目录。每轮另选输出目录；已有分块只能用于同一配置的继续运行，修改仿真代码后请另建目录。

```matlab
verify_position_extension('results/new_run/preflight');
run_position_extension('ULA','Mode','smoke','OutputDir','results/new_run/smoke_ULA');
run_position_extension('UPA','Mode','smoke','OutputDir','results/new_run/smoke_UPA');
run_position_extension('ULA','Mode','pilot','OutputDir','results/new_run/pilot_ULA');
run_position_extension('UPA','Mode','pilot','OutputDir','results/new_run/pilot_UPA');
run_position_extension('ULA','Mode','full','OutputDir','results/new_run/ULA');
run_position_extension('UPA','Mode','full','OutputDir','results/new_run/UPA');
finalize_position_extension('ULA','results/new_run/ULA');
finalize_position_extension('UPA','results/new_run/UPA');
benchmark_position_extension('results/new_run');
```

随后运行：

```text
python analyze_position_extension.py results/new_run
```

## 范围

主实验覆盖原E1/E2/E3及BF图；B=8、观测30 dB下补充坐标预算、每维4–16 bit方向量化、未量化位置参考和加权定位。坐标统一相位敏感度分配，不单独优化UE编码。主图保留原sqrt(mean(G))口径，预算BF图明确采用mean(G)。主吞吐量为固定总发射功率、固定rho的名义吞吐量，不扣除反馈资源。

原Type-I/II仍由UE实测信道设计，即使显示在CPU面板内也不更改相位来源。加权定位只作为单独的观测能量权重变体，不改变主方法。更复杂NLOS、移动、硬件未知相位及实际UCI开销不在本轮范围内。
