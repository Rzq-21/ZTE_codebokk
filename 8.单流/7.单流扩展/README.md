## 已完成结果

[完整实验报告](results/dual_v1_20261022/双极化多流仿真报告.md)包含8组PNG/FIG、逐样本配对比较和CPU残差诊断；[全量审计](results/dual_v1_20261022/complete_audit.json)已通过。两阵列正式/补充共297600条记录，每配置400位置，另有原秩诊断3200条、独立pilot 9792条和CPU诊断9600条。

B=8、观测30dB、R3时，同硬件、同功率的UE双流相对单流吞吐量提高约63%–65%（ULA）/79%–80%（UPA），涵盖LOS和混合信道。双流总反馈240/252bit，相对相同系数量化的全方向对照288/328bit节省16.67%/23.17%；速率差距在本定点小于0.15%。这些结论条件于下述受控极化模型。

CPU差距需要分别判断：ULA标称LOS双流为168.67Mbps，保持波束不变、将系数模型位置替换为真实位置后为177.62Mbps，真实有效信道参考为179.65Mbps；UPA标称LOS对应323.81/324.26/324.35Mbps。定位与坐标误差、局部平面LOS模型残差与极化失配应分开解释，不能把所有CPU损失归因于未知极化。真实位置/信道两项仅是oracle诊断。

## 模型与公平比较

- 沿用第6目录400个位置、10个AP的几何、7 GHz、半波长间距、LOS/六散射体K=10模型、20 MHz与固定数据噪声尺度。每个原空间阵元改为两个±45°极化端口，UE为4个空间位置×2极化=8端口。
- 同一双极化硬件分别发送1流和2流；总功率为1，所有可实施方案每AP总功率为1/B。不会给每流各分配一次原总功率。
- LOS采用横向投影Jones矩阵，散射使用两段横向基和2×2路径耦合矩阵，交叉极化幅度比对应XPR=10 dB；极化按中心射线方向计算，每条路径Jones矩阵Frobenius范数归一到√2。保留逐阵元球面传播距离，散射总矩阵逐AP归一到LOS范数。**这是受控双极化扩展，不是完整3GPP TR 38.901模型或射线追踪验证。**
- 理想极化场景已知端口方向；失配场景分别为UE绕全局y轴倾斜20°、AP第二极化端口差分相位RMS 15°、二者叠加。相位偏差在10个物理AP上冻结，不随用户/方法重抽。CPU默认不知道偏差，UE通过有噪观测感知它们。
- 新噪声为8×(2Nap)，逐物理AP种子取原种子+8000000；所有方法、流数和失配场景共用同一标准复高斯噪声，实际方差按当前参与AP的真实信道平均元素功率和观测SNR计算。

## 实现边界与反馈

各AP采用 `W_b=(I₂⊗f_b(p_hat)) C_b`，其中`C_b`为2×Ns矩阵。位置消息仍按第6目录相位敏感度分配：ULA 24bit，UPA 36bit，R3/R5共用该分配。

UE先从每个参考AP的16个接收/发射极化端口组合观测中，按观测能量选4个空间快拍，再调用原HAQSE；无权射线定位、坐标量化、全部AP几何波束沿用原实现。选快拍仅用观测，不使用真实路径或真实位置。

- `POS_CPU`：CPU仅接收整数位置消息，以公开极化方向和LOS几何模型设计低维系数。不反馈UE系数。
- `POS_CPU_CALIBRATED`：仅在失配实验中附加的诊断，CPU额外已知真实UE倾角与/或AP端口相位校准值，用相同解码位置与波束设计。表中bit只统计位置，不包含这些额外校准信息的获取或传输成本，不能当作未知姿态下的纯位置可实施方案。
- `POS_UE_Q`：UE以有噪有效信道设计系数，逐AP归一。每个复系数幅度3bit、相位4bit；每流固定一个全局相位锚，不发送该相位。CPU仅按整数消息解码并重新归一。
- 系数开销为`2*B*Ns*(qA+qP)-Ns*qP`，B=8时单流108bit、双流216bit。总开销再加位置24/36bit。幅度端点均匀量化，圆周相位均匀量化；不另外重复计共相位。
- `FULLDIR_UE_Q`：每AP反馈完整公共DFT空间波束索引，再采用完全相同的低维系数量化与功率约束；ULA每AP9bit、UPA每AP14bit。它是项目内的全方向反馈对照，**不是完整NR Type-I码本实现**。
- 系数以有效信道前Ns个右奇异向量初始化、逐AP做Frobenius归一，属于可复现的启发式设计，不声称解决每AP功率约束下的全局最优问题。
- `CAP_RANK_LE_N`为真实信道、总功率约束、最多N流的注水容量上界，放松每AP功率约束；上界不计有限反馈。连续系数对照和2/3、4/5bit补充扫描仅在B=8、观测30dB运行。

同时记录联合解码`logdet`速率、线性MMSE各流SINR和速率。主比较使用MMSE速率；1流时两者相同。两流等功率SVD仅为诊断参考，不冒充一般容量上界。

## 冻结实验范围

1. 原单极化信道：B=8、观测30dB存档位置R3/R5，400位置×LOS/MIX×ULA/UPA；检查真实信道与位置波束子空间的第二奇异值、单/双流等功率理想速率及最多两流容量。
2. 双极化单流与双流：B=8时观测20/25/30/35/40dB，观测30dB时B=5…10，去重后10个横轴点；两个阵列、两种信道、R3/R5、每点400位置。
3. B=8、观测30dB增加连续系数和幅度/相位bit扫描，检验量化代价。
4. 三种极化失配固定B=8、观测30dB，保持400位置、两种信道、两种阵列与相同设计程序。

独立pilot采用24个额外位置、散射系数和种子；通过信息边界、整数合法性、总功率/每AP功率、容量上界、单流速率一致性等核查后再运行正式400位置。

## 复现

需要本仓库第6目录的冻结输入、`+upa`、`+ula`、`+posfb`和`lib`，不复制其650MB历史结果。MATLAB R2024a进入本目录。公开计算源码和输入SHA256清单已附；自行更改源码时，应在计算前运行`python analyze_dual_extension.py --freeze`记录自己的版本，使用新的结果目录，勿将其视为原发布版本的校验。

```matlab
run_rank_diagnostic;
verify_dual_extension;
run_dual_extension('ULA','Mode','pilot');
run_dual_extension('UPA','Mode','pilot');
run_dual_extension('ULA','Mode','full');
run_dual_extension('UPA','Mode','full');
finalize_dual_extension;
run_cpu_diagnostics;
```

随后运行`python analyze_dual_extension.py`进行独立整数消息审计和配对比较，并生成完整报告、更新原第5目录报告。Python依赖numpy/pandas。当前runner按已存在的完整20样本块续跑；`OutputDir`可指定新的输出目录，汇总和分析脚本默认读取本发布的固定结果根目录，自定义根目录时需相应调整。

实验记录、配对比较、图与审计输出至`results/dual_v1_20261022/`。CSV保留逐样本速率、功率、定位误差、反馈bit和整数消息；公共配置保存路径耦合、相位偏差和种子规则。`experiment_contract.json`先于正式结果写出。两个正式阵列各148800条记录，独立pilot位于`pilot_verified_ULA/UPA`，每阵列24位置、4896条。

CPU残差诊断固定R3、B=8、观测30dB，保持主实验解码位置生成的同一组波束，分别用估计位置、真实位置、真实有效信道设计系数；后两项为无有限反馈预算的oracle诊断，不能混入可实施方案或称为一般容量上界。诊断重算主实验CPU速率并核验一致，用于区分定位与平面LOS模型/多径的残差。

每个实验流数固定、双方预先约定，不含自适应RI反馈。结果仅计消息有效载荷，未计协议头、参考AP/码本配置或校准开销，亦未扣除导频和反馈占用后的净吞吐量。
